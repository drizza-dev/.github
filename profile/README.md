# drizza

drizza is a local dashboard for your daily work briefing across GitHub and Slack.
It runs on your machine: a server bound to `127.0.0.1`, backed by SQLite.
Your agent (Claude Code, Codex) pushes the briefing to drizza over MCP.
Your credentials never leave your machine.

## Get started

```sh
npx drizza
```
